# 字型

| 檔案 | 字型 | 授權 |
| --- | --- | --- |
| `NotoSerifTC-Medium.ttf` | Noto Serif TC（思源宋體繁體中文），Medium 字重 | SIL Open Font License 1.1，全文見 `OFL.txt` |

來源是 Google Fonts 的官方倉庫 `google/fonts` 中 `ofl/notoseriftc/` 的可變字型（版本 2.003）。為了不必在引擎裡處理可變字重，用 fontTools 把字重固定在 500 後另存，字符沒有刪減。

這套授權允許免費商用、修改、隨遊戲散布，條件是保留授權檔，且不得單獨販售字型本身。
