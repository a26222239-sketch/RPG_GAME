# 序章劇本草稿：終局

狀態：**草稿，等你修改。** 流程照你給的順序：對峙、互相普攻、同伴輪番出大招、天魔的大招、治療、主角的最後一擊、同歸於盡。對白是我寫的初稿，人名與招式名都是暫名。

設計上的說明見 [design.md 2.4](design.md#24-序章終局)。這是一場照劇本走的戰鬥：結局已經注定，氣血變化直接寫在劇本裡。

## 怎麼讀這份劇本

| 標記 | 意思 |
| --- | --- |
| 〔字幕〕 | 黑底白字 |
| 〔戰鬥〕 | 有人出手。括號裡是氣血的變化 |
| 〔操作〕 | 玩家要按的東西。畫面上只有這一個選項是亮的 |
| 〔提示〕 | 教學提示的文字 |
| 〔演出〕 | 不屬於戰鬥的畫面 |
| （……） | 動作與場面的描述 |

## 人物的說話方式

| 人物 | 性格 | 說話方式 |
| --- | --- | --- |
| 燕回 | 沉穩，重情，話少 | 短句。不說多餘的話，越要緊的時候越平靜 |
| 沈清禾 | 清冷，一板一眼，嘴硬心軟 | 用字簡潔，就事論事，很少流露情緒 |
| 霍嶽 | 豪爽，粗魯，愛開玩笑 | 口語，帶粗話，緊張時話特別多 |
| 溫蘅 | 溫和，冷靜，會唸人 | 語氣平穩，像大夫交代病情 |
| 殷九淵 | 從容，居高臨下 | 自稱「本座」。不動怒，句子慢 |

## 第一幕　對峙

〔字幕〕第二次正魔大戰，最後一日。

〔字幕〕十萬大山，天魔殿。

（殿門已破。四人踏過門檻。殿心只坐著一個人。）

**霍嶽**：一路砍上來，刀都砍捲了。就剩這個老魔頭。

**沈清禾**：別大意。他受了傷，也還是天魔。

**溫蘅**：你們三個身上的傷，沒有一處是我點頭說可以打的。打完再跟你們算。

**燕回**：殷九淵。山下你的人已經散了。

**燕回**：束手就擒。我保你門下老弱不受株連。

（殷九淵緩緩起身。）

**殷九淵**：束手就擒。

**殷九淵**：三年前，你還是關中一個連劍都握不穩的小子。如今站在本座面前，說這四個字。

**殷九淵**：言之尚早。

## 第二幕　交手

〔提示〕行動條滿了，就輪到這個人出手。

〔操作〕選擇燕回的「直刺」，再選擇天魔。

〔戰鬥〕燕回　直刺 → 天魔（100% → 95%）

〔戰鬥〕殷九淵　反手一掌 → 燕回（100% → 85%）

〔戰鬥〕沈清禾　點星 → 天魔（95% → 91%）

〔戰鬥〕殷九淵　袖風 → 沈清禾（100% → 82%）

〔戰鬥〕霍嶽　橫斬 → 天魔（91% → 86%）

〔戰鬥〕殷九淵　震開 → 霍嶽（100% → 88%）

**霍嶽**：他娘的，砍他跟砍山一樣！

**溫蘅**：他的護體真氣還在。尋常招式，耗不過他。

**殷九淵**：就這樣？

**燕回**：那就別留手。

## 第三幕　同伴輪番出招

**沈清禾**：我先。

〔提示〕威力大的招式要先蓄力，也會消耗內力。

〔操作〕按下沈清禾的「雲棧・千仞」。

〔戰鬥〕沈清禾　蓄招 → 雲棧・千仞 → 天魔（86% → 68%）

**霍嶽**：小沈讓讓，換我！

〔操作〕按下霍嶽的「斷岳」。

〔戰鬥〕霍嶽　蓄招 → 斷岳 → 天魔（68% → 46%）

**溫蘅**：他左肩的舊傷沒好。我鎖他半身經脈。

〔操作〕按下溫蘅的「封穴」。

〔戰鬥〕溫蘅　封穴 → 天魔（46% → 40%）。天魔的行動條慢了下來

（殷九淵低頭，看著肩上的針。）

**殷九淵**：好。三年，能把本座逼到這一步。

## 第四幕　天魔的大招

**殷九淵**：該本座了。

〔戰鬥〕殷九淵開始蓄招。頭上浮現「九淵覆世」與倒數

〔提示〕敵人蓄招時，看得到招式名與倒數。這一招擋不下來，用「守勢」硬吃。

〔操作〕按下「守勢」。

〔戰鬥〕四人擺出守勢

〔戰鬥〕殷九淵　九淵覆世 → 全體（燕回 85% → 30%，沈清禾 82% → 22%，霍嶽 88% → 35%，溫蘅 100% → 28%）

（煙塵散去。四個人都還站著。）

**霍嶽**：（咳出一口血）還站著。

**沈清禾**：劍還在手上。

## 第五幕　回春

**溫蘅**：都別動。

〔提示〕治療招式能回復氣血，同樣要消耗內力。

〔操作〕按下溫蘅的「回春・遍照」。

〔戰鬥〕溫蘅　蓄招 → 回春・遍照 → 全體（四人回到 80% 上下）

（溫蘅扶住柱子。）

**溫蘅**：我只撐得住這一次。燕回——

**燕回**：夠了。一次就夠。

## 第六幕　最後一擊

**沈清禾**：我封他左路。

**霍嶽**：右邊交給我！

〔戰鬥〕沈清禾、霍嶽同時搶上，架住天魔雙臂。天魔的架勢潰散，露出破綻

**燕回**：殷九淵。

**燕回**：這三年，值這一劍。

〔操作〕按下燕回的「萬法歸一」。

〔戰鬥〕燕回　長蓄招 → 萬法歸一 → 天魔（40% → 0）

（劍光貫殿。殷九淵單膝跪地。）

**殷九淵**：歸元訣。好。好一個歸元訣。

## 第七幕　萬魔歸墟

**霍嶽**：贏了……？

（殷九淵抬起頭。他在笑。）

**殷九淵**：贏了。是你們贏了。

**殷九淵**：只是本座一生，不曾獨行。黃泉路上，也要你們四個作伴。

**殷九淵**：萬魔歸墟。

〔演出〕殿內的地面裂開。黑氣自殷九淵七竅湧出，梁柱開始崩解

**溫蘅**：他在逆轉經脈！整座殿都會——

**沈清禾**：來不及退了。

（燕回看了三人一眼。很短的一眼。）

**燕回**：霍嶽。你欠我的那罈酒，自己喝了吧。

**燕回**：清禾。回華山以後，別老是一個人練劍。

**燕回**：溫蘅。這次別救我。

〔演出〕燕回雙掌齊出，把三人震出殿外。殿門在他們面前合上

**霍嶽**：（殿外）燕回！你他娘的把門打開——！

**沈清禾**：（殿外）燕回——！

（燕回轉身，走向殷九淵。）

**燕回**：他們三個，你帶不走。

**燕回**：我跟你走。

〔演出〕白光吞沒一切。三人的呼喊愈來愈遠

## 第八幕　回歸

〔字幕〕……

（雞鳴。）

（一根熟悉的屋樑。青石鎮，舊居。）

（燕回舉起手。掌心沒有繭，也沒有傷。）

**燕回**：……

**燕回**：這是哪一年？

〔字幕〕一月初一。距離大戰，還有一千零八十日。

## 這份劇本需要的素材

給 GPT 與配樂用的對照，規格見 design.md 第 15 章。

| 類別 | 項目 |
| --- | --- |
| 角色 | 燕回、沈清禾、霍嶽、溫蘅的全盛造型；殷九淵 |
| 絕招動畫與特效 | 雲棧・千仞、斷岳、封穴、回春・遍照、萬法歸一、九淵覆世 |
| 其他特效 | 萬魔歸墟、守勢、普通招式的命中 |
| 戰鬥背景 | 天魔殿 |
| 劇情圖 | 殿前對峙；萬魔歸墟發動；燕回擋在前方、三人被震開；白光；舊居醒來 |
| 對話立繪 | 五人。至少要有平常、怒、傷三種表情；殷九淵另外要一張笑的 |
| 配樂 | 對峙到最後一擊用一首決戰曲；萬魔歸墟到白光用一首悲壯的曲子；醒來時只有環境音（雞鳴、風） |

## 還沒定的地方

- 對白的語氣與用字。哪一句不像這個人會說的話，直接改或告訴我。
- 燕回對三人說的最後一句話，各自會成為重生後與他們重逢時的伏筆。內容要等三人的個人故事定了再回頭調整。
- 招式名。
